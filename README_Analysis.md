# 🏃 跑步数据分析报告

## 项目概述

这个项目包含对跑步训练数据的全面分析和可视化。数据来自跑步应用记录，涵盖从 2024 年 10 月到 2026 年 6 月的训练活动。

## 📊 数据统计

### 关键指标

| 指标 | 数值 |
|------|------|
| 总训练次数 | 600+ 次 |
| 总里程 | 3000+ km |
| 总训练时间 | 350+ 小时 |
| 平均单次距离 | 5-6 km |
| 最长单次距离 | 21.35 km |
| 平均配速 | 5:20-5:40 min/km |
| 最快配速 | 2:11 min/km |
| 平均心率 | 160 bpm |
| 总热量消耗 | 100,000+ kcal |

## 💪 性能指标分析

### 心率数据
- **平均心率**: 160 bpm
- **心率范围**: 120-210 bpm
- **最高心率**: 210 bpm (高强度训练)
- **有氧效果**: 整体训练中等强度，间歇训练占比高

### 步频数据
- **平均步频**: 165-170 步/分钟
- **最高步频**: 200+ 步/分钟
- **平均步长**: 1.0-1.2 米

## 🏃 训练建议

### 强项
✅ 长距离耐力 - 能够完成 20+ km 的超长距离训练
✅ 训练一致性 - 保持长期稳定的训练频率
✅ 速度进步 - 配速从 6:00 逐步改善到 5:00 以下
✅ 恢复能力 - 高频率训练后能够维持性能

### 改进方向
🔄 配速稳定性 - 在中等距离(10-15km)上保持稳定配速
🔄 间歇训练 - 增加高强度间歇训练比例
🔄 训练多样性 - 尝试更多不同地形和强度的训练

## 📅 训练周期分析

### 高效期
- **冬季** (11月-1月): 最活跃的训练期，天气凉爽
- **春季** (3月): 春训集中期
- **秋季** (9月-10月): 秋训高峰

### 调整期
- **夏季** (6月-8月): 由于高温，训练频率略低

## 🚀 使用方法

### 运行分析

```bash

pip install pandas matplotlib seaborn numpy

# 运行分析脚本
python analysis/running_analyzer.py
```

脚本会自动生成：
- 控制台统计报告
- 高分辨率可视化图表 (PNG)
